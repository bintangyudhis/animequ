# Animequ

Website informasi anime yang datanya diambil dari AniList API. Pengunjung bisa melihat anime yang sedang tayang, anime yang sedang tren, menyimpan favorit, dan melihat riwayat tontonan. Halaman detail menampilkan trailer dan tautan ke platform resmi. Situs ini tidak menyediakan video bajakan.

## Fitur

Fitur berikut masih berupa rencana dan belum diimplementasikan:

- Daftar anime ongoing dan trending dari AniList
- Pencarian anime berdasarkan judul
- Halaman detail berisi sinopsis, trailer, dan tautan platform resmi
- Daftar favorit yang disimpan pengunjung
- Riwayat anime yang pernah dibuka

## Teknologi

Rencana teknologi yang akan dipakai:

- Next.js untuk antarmuka web
- AniList API (GraphQL) sebagai sumber data anime, gratis dan tanpa API key

## Status

Proyek dalam pengembangan. Kode utama belum masuk ke repositori ini. Dokumentasi instalasi dan cara menjalankan akan dilengkapi setelah kode tersedia.
